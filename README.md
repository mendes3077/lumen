# Lúmen

Estúdio criativo no navegador: conversa, imagem, música, vídeo, clipe, avatar 3D, livros e tom.

## Rodar

```bash
npm install
npm run models
npm run dev
```

Abre em `http://localhost:8080`.

`npm run models` baixa os dois avatares 3D (Michelle e Xbot) usados na seção Avatar.

Conversa, imagem com IA, vídeo com IA, resumo com IA e voz natural usam a cota da conta Grok. Música, editor de foto, clipe, avatar, resumo rápido e leitura do navegador funcionam neste aparelho.

O app não gera nem edita conteúdo sexual.
